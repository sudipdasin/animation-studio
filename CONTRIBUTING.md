# Contributing

Please file an issue with reproducible steps before substantial changes. Fork the repository after publication, work on a feature branch and open a pull request. Include a test plan and screenshots for UI changes. Preserve existing modeling/sculpting/painting functionality. Mark unfinished work as experimental and keep it out of stable workspaces. Never upload personal project data without permission.

## Suggested test matrix

- Chrome/Chromium and Firefox on Linux, Windows, Android.
- Create and select cube/sphere independently; sculpt sphere without affecting cube.
- Inflate, deflate, smooth, flatten, crease, grab, symmetry, undo/redo.
- Paint vertex color, fill, reset; keyframe playback; save/load JSON; export image.
- Resize and touch input.
